# lociq-areas

Published static neighborhood profiles for [LOCIQ](https://lociq.ai) — housing
age, building era, property mix, and ownership characteristics for U.S.
neighborhoods, derived from public county assessor and ownership records.

Pages are served at **[areas.lociq.ai](https://areas.lociq.ai)**.

This repository holds the rendered static output only. Pages are generated from
LOCIQ's property-intelligence data and published here as a deploy artifact.
